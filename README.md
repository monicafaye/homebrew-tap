# Homebrew Tap for TypX

Install [TypX](https://github.com/monicafaye/TypX) on macOS or Linux via Homebrew:

```bash
brew tap monicafaye/tap
brew install typx
```

Or in a single command:

```bash
brew install monicafaye/tap/typx
```

For full LSP diagnostics, completion, hover, formatting, and live preview, also install `tinymist`:

```bash
brew install tinymist
```
